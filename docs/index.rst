Overview
--------

Colorify Studio is a cutting-edge web application that transforms how the textile industry approaches color matching and design. Built with Django and powered by AI, it enables users to:

* Upload TIFF/PSD files with multiple layers
* Extract and analyze colors from images
* Generate harmonious color palettes
* Apply AI-powered color transformations
* Export modified designs in various formats
* Manage subscriptions and user accounts

Key Features
------------

🎨 **AI-Powered Color Matching**
   Advanced algorithms for precise color analysis and matching

🖼️ **Multi-Layer File Support**
   Handle complex TIFF and PSD files with multiple design layers

🎯 **Subscription Management**
   Flexible subscription plans with Razorpay integration

👥 **User Management**
   Complete authentication system with social login support

📊 **Analytics Dashboard**
   Comprehensive admin interface with analytics

🔒 **Security**
   Enterprise-grade security with CSRF protection and secure authentication
